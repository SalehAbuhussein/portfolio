## Platform

web

## Users
Hiring managers and technical recruiters filling frontend or full-stack roles (Angular, .NET). They arrive from a CV, LinkedIn or GitHub link, skim for under a minute, and decide whether to interview.

## Product Purpose
Personal portfolio of Saleh Abuhussein. Success: a hiring manager understands within seconds that he is a production Angular developer who also builds ASP.NET Core and SQL Server back ends, and reaches out.

## Positioning
Frontend + .NET full-stack: 3+ years of production Angular at Motory (rebuilt a jQuery marketplace into Angular with a team of four, live auctions on Mazad), plus hand-designed SQL Server databases and ASP.NET Core APIs in his own projects.

## Operating Context
Visitors come from LinkedIn, CV links and GitHub, on desktop and phone. Static site on GitHub Pages (Angular 22, static prerender). All content lives in `src/app/content.ts`.

## Capabilities and Constraints
Sections: about, skills, projects, experience, contact. No backend, no forms. Must stay a static prerendered Angular app deployed by `.github/workflows/deploy.yml`.

## Brand Commitments
Plain, human voice: no em dashes, no emoji, no hype words, sentence-case headings. Angular is named before .NET everywhere.

## Evidence on Hand
- Experience, education, summary: LinkedIn export, captured in `src/app/content.ts`.
- Photo: GitHub avatar https://avatars.githubusercontent.com/u/98553562?v=4
- Projects: public GitHub repos (Clinic-Management-System, aspnetcore-guide, Angular-Material-Storybook, Angular-Movies, Car-Rental-System, Cafe-POS); DVLD has no public repo.
- No testimonials, client logos, metrics beyond the LinkedIn facts. Do not fabricate any.

## Product Principles
1. Proof over adjectives: lead with the Motory rebuild and concrete results.
2. Scannable in 30 seconds by a busy hiring manager.
3. Every claim traces to LinkedIn or a public repo.
4. Contact is never more than one click away.
